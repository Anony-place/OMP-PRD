Why getRandomValues matters

Math.random() is a predictable pseudo-random generator — its future outputs can be reconstructed from observed ones. crypto.getRandomValues() draws from the operating system's CSPRNG, the same source browsers use for TLS keys. OMP additionally uses rejection sampling and a secure Fisher–Yates shuffle, so output is unbiased.

How OMP builds each password

  • One guaranteed character from every selected type
  • Remaining positions drawn uniformly from the combined pool
  • Everything shuffled with CSPRNG randomness

Need something memorable?

Random words beat random characters for memorization. A 5-word passphrase from a 1,296-word list carries ~52 bits; 7 words ~72 bits.
