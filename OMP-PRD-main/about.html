About

Password security, without the account

OopsMyPassword (OMP) is a privacy-first toolkit for understanding, testing and improving passwords — built so that using it never requires trusting it.

What OMP is

OMP is a set of free, browser-based tools: a real-time password strength checker, a cryptographically-secure generator, a passphrase generator, an entropy calculator, a password health audit, an educational breach-check demo, and a library of practical guides. Every tool works the moment the page loads — no sign-up wall, no trial, no email field.

Why it exists

Two things bothered us about the status quo:

  • Most "password checkers" ask you to hand your password to a server. Even well-meaning ones create a habit nobody should have: typing credentials into websites that ask for them.
  • Security advice is often theater. Fake precision ("this password would take 34 quadrillion years"), fake counters, unlabeled demos, dark patterns pushing accounts. We wanted tools that are honest about what they compute.

The privacy-first philosophy

OMP is architected so password analysis runs in JavaScript on your device. No password inputs cross the network. Optional contact details are separate from the tools and local learning records. The best data-protection policy is data you never collect.

Security principles we hold to

  • Client-side by default. If a feature can run locally, it runs locally.
  • CSPRNG or nothing. Generation uses crypto.getRandomValues() exclusively — never Math.random().
  • No fake claims. Estimates are labeled estimates; demos are labeled demos; unfinished tools say "Coming Soon".
  • Minimal attack surface. Password analysis stays local; online publishing, optional email updates and contact messages use documented services.
  • Teach, don't lecture. Every result links to a plain-language explanation.

No account required

No learner login is required. Your theme, checklist, optional Academy name and learning progress stay on this browser/device. You can back up or clear Academy data in Device settings.

No unnecessary data collection

OMP does not run analytics that could touch what you type, does not place passwords in URLs, and does not log inputs. If a future feature ever needs a network call (like an opt-in breach lookup), it will be documented, consent-based, and built on k-anonymity.

Who it's for

Anyone with accounts. Students learning security basics, developers who want clean reference tools, and everyone who has ever reused a password and meant to fix it.
