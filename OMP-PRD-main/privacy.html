Privacy Policy

Last updated: September 29, 2026. Plain language, because privacy policies should be read, not scrolled past.

The one-paragraph version

Passwords you enter into OopsMyPassword's local tools are processed in your browser's memory and nowhere else. We do not store password history, we do not put passwords in URLs, we do not send what you type to analytics, and there are no user accounts that could tie anything to you.

1. Local processing of passwords

  • The Password Checker, Generator, Passphrase Generator, Entropy Calculator and Password Health audit run entirely client-side. The password value lives only in browser memory while the tab is open.
  • We do not transmit, log, persist, or otherwise observe password inputs.
  • Passwords are never included in URLs, query parameters, hash fragments, or referrer headers.
  • If this site ever includes error reporting or analytics, it is configured such that input values — passwords included — can never be part of a payload.

2. Device-only learning, no learner login

Public learning and tools require no login. Academy stores an optional display name, course-scoped lesson progress, self-check scores and reading bookmarks in localStorage. Theme preferences and Security Checklist progress are also local. This data does not sync to any server. Clearing browser data removes it; use Academy Device settings to download/restore a backup or reset Academy data. Backups include your name and progress, so keep them private. Shared browsers share these local records. Site administrators use a separate protected publishing login; it is not required for visitors. Historical server-issued certificates and learner records, if any, are not automatically deleted or imported by this change.

3. Password breach check

The Breach Check tool uses the zero-knowledge k-anonymity model to detect compromised passwords without exposing credentials. When you enter a password, your browser calculates its SHA-1 hash locally using the standard WebCrypto API. Only the first five hexadecimal characters of that hash (the anonymous range prefix) are sent to the public Have I Been Pwned range API (api.pwnedpasswords.com). Neither the password nor the full hash is ever transmitted, logged, or stored by OopsMyPassword. If the third-party range API is unreachable or your device is offline, the tool automatically falls back to comparing against an embedded local demo corpus without making any network requests.

4. Hosting and server logs

Like nearly every website, the static-hosting provider serving these files processes standard technical metadata (IP address, user agent, requested path) to deliver pages, and may retain it under its own security, reliability and retention policies. We do not sell, rent, or share that data.

5. Third-party services

Firebase Hosting serves the site. Supabase supplies published articles/products and contact-message storage; some publishing interfaces load the Supabase library from esm.sh. These requests expose normal network metadata to those providers but do not include password inputs or local Academy progress. No advertising analytics are included in this build. Contact messages include the name, email and message you submit.

6. Children

OMP is intended for a general audience. Password tools and Academy learning need no email. Do not submit unnecessary personal or sensitive information in an optional subscription or contact message.

7. Changes to this policy

Material changes will be posted on this page with an updated date. We will never claim compliance certifications we have not obtained; where a formal legal regime applies to how you use this site, consult qualified counsel.

8. Contact

Privacy questions and security reports: see the contact page or our security policy.
