What these are for

  • Test fixtures and sample data
  • Non-guessable IDs (128-bit Base64URL ≈ UUIDv4 strength)

Building production secrets? API keys and session tokens should be generated by your server-side CSPRNG and stored hashed. This tool is for convenience and testing — by design it shows values on screen.
