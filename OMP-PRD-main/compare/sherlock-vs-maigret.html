Sherlock vs Maigret: Username OSINT Tool Comparison

Compare Sherlock and Maigret for username OSINT investigations across site coverage, profile metadata parsing, recursive handle pivoting, and HTML/PDF reporting.

Executive Verdict: When to Choose Each

Choose Sherlock if…

Best for fast, lightweight CLI username checks across 400+ mainstream social platforms with minimal dependencies.

Choose Maigret if…

Best for deep OSINT investigations requiring profile bio parsing, linked account extraction, and visual HTML/XMind reports.

Feature-by-Feature Technical Matrix

Dimension Sherlock Maigret
Site Database Size 400+ curated mainstream social & developer sites 2,500+ global, regional, and forum platforms
Profile Content Parsing Checks account existence (HTTP status / response string) Extracts full name, bio, avatar URL, creation date, and linked handles
Recursive Pivoting Single-pass username check Automatically pivots onto new usernames/IDs discovered on profiles
False Positive Handling Curated regex/status checks on high-reliability sites Tag-based site filtering (--tags) and heuristic page analysis
Reporting Formats Plain text, CSV, JSON, XLSX Interactive HTML report, PDF, XMind mindmap, JSON
Tor & Proxy Support Supports Tor (-t) and custom HTTP/SOCKS proxies Supports Tor, proxies, and custom cookie jars

Side-by-Side CLI & Operational Workflow

Sherlock Example

# Fast high-confidence username check with Sherlock
sherlock target_user --timeout 10 --print-found --csv

Maigret Example

# Deep profile extraction + HTML report with Maigret
maigret target_user --top-sites 300 --html

Frequently Asked Questions

Is Maigret a fork of Sherlock?

Maigret started as a Python fork of Sherlock and added deep HTML/JSON profile scraping, recursive username pivoting, and standalone HTML/PDF visual dossier generation.

How do OSINT analysts verify false positives from username tools?

Many sites return HTTP 200 even for non-existent users. Always open discovered profile URLs in an isolated browser profile and cross-check avatars, bios, and creation timestamps before attributing an account.
