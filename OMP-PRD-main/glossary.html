Cybersecurity, Cryptography & OSINT Glossary

Thirty core security concepts — from k-anonymity, Argon2id, and passkeys to IDOR, SSRF, Kerberoasting, and Google Dorking — explained with architecture breakdowns and defensive checklists.

Cryptography & Privacy

k-Anonymity

k-Anonymity is a privacy property where a lookup or record cannot be distinguished from at least k-1 other items in the same set, allowing breach checks without revealing the secret queried.

Deep-dive & defenses → Breach Check (k-Anonymity Demo)
Cryptography & Privacy

Argon2id

Argon2id is the modern winner of the Password Hashing Competition that combines memory-hard resistance against GPU cracking (Argon2d) with side-channel timing resistance (Argon2i).

Deep-dive & defenses → Hash & JWT Inspector
Authentication & Identity

Credential Stuffing

Credential stuffing is an automated cyberattack where bots replay millions of leaked username-and-password pairs from one data breach across other websites to hijack accounts that reused the same password.

Deep-dive & defenses → Password Generator
Authentication & Identity

Password Spraying

Password spraying is a low-and-slow authentication attack that tests one common password (such as Summer2026! or Welcome123) across thousands of user accounts to avoid triggering per-account lockout thresholds.

Deep-dive & defenses → Password Strength Checker
Authentication & Identity

Passkey (FIDO2 / WebAuthn)

A passkey is a phishing-resistant digital credential based on FIDO2 and WebAuthn public-key cryptography that replaces passwords with a cryptographic key pair bound to the website genuine domain.

Deep-dive & defenses → YubiKey vs Passkeys Comparison
Authentication & Identity

TOTP (Time-Based One-Time Password)

TOTP (RFC 6238) is an offline two-factor authentication algorithm that computes a short-lived 6- to 8-digit code from a shared secret key and the current Unix timestamp, rotating every 30 seconds.

Deep-dive & defenses → Security Checklist
Phishing & Social Engineering

Browser-in-the-Browser (BitB) Phishing

Browser-in-the-Browser (BitB) is a phishing technique that renders a fake HTML/CSS popup window inside a webpage to imitate a legitimate Google, Microsoft, or Apple OAuth login dialog complete with a spoofed HTTPS address bar.

Deep-dive & defenses → Phishing URL Risk Scanner
Web App Security

IDOR (Insecure Direct Object Reference)

Insecure Direct Object Reference (IDOR), a form of Broken Object Level Authorization (BOLA), occurs when an application uses a client-supplied identifier (such as ?invoice_id=1042) to fetch or modify a record without verifying that the logged-in user owns that object.

Deep-dive & defenses → Burp Suite vs OWASP ZAP
Web App Security

SSRF (Server-Side Request Forgery)

Server-Side Request Forgery (SSRF) is a web vulnerability where an attacker tricks a backend server into making HTTP or network requests to internal-only services, localhost ports, or cloud metadata endpoints.

Deep-dive & defenses → HTTP Security Headers Cheat Sheet
Web App Security

XSS (Cross-Site Scripting)

Cross-Site Scripting (XSS) is an injection vulnerability where untrusted data is rendered into a web page without context-aware output encoding, allowing an attacker to execute arbitrary JavaScript in another user browser session.

Deep-dive & defenses → HTTP Security Headers Cheat Sheet
Web App Security

SQL Injection (SQLi)

SQL Injection (SQLi) is a critical vulnerability where user input is concatenated directly into a database query string, allowing an attacker to alter the SQL syntax and read, modify, or delete arbitrary database data.

Deep-dive & defenses → sqlmap Cheat Sheet
Web App Security

CSRF (Cross-Site Request Forgery)

Cross-Site Request Forgery (CSRF) is an attack that tricks an authenticated user browser into sending an unwanted state-changing HTTP request (such as changing an email or transferring funds) to a web application where they are currently signed in.

Deep-dive & defenses → HTTP Security Headers Cheat Sheet
Authentication & Identity

JWT (JSON Web Token)

A JSON Web Token (JWT, RFC 7519) is a compact, URL-safe token format consisting of a Base64URL-encoded JSON Header, Payload (claims), and cryptographic Signature separated by dots.

Deep-dive & defenses → Client-Side Hash & JWT Inspector
OSINT & Recon

Subdomain Takeover

Subdomain takeover occurs when a subdomain (such as promo.example.com) has a dangling DNS CNAME or A record pointing to an external cloud resource (S3 bucket, GitHub Pages, Azure App) that has been deleted or unclaimed, allowing an attacker to register that cloud resource and serve content under the organization legitimate subdomain.

Deep-dive & defenses → Amass vs Subfinder Comparison
OSINT & Recon

Google Dorking (Search Engine Recon)

Google Dorking (Google Hacking) is the use of advanced search engine operators—such as site:, filetype:, inurl:, intitle:, and intext:—to locate publicly indexed configuration files, exposed directories, login portals, and sensitive documents.

Deep-dive & defenses → Interactive Google Dork Builder
Phishing & Social Engineering

IDN Homograph Attack (Punycode Spoofing)

An IDN homograph attack registers a domain name containing non-ASCII Unicode characters (such as Cyrillic "а" instead of Latin "a") that look visually identical to a trusted brand domain in order to deceive users into visiting a phishing site.

Deep-dive & defenses → Phishing URL Risk Scanner
Phishing & Social Engineering

Typosquatting & Combo-Squatting

Typosquatting (and combo-squatting) is the registration of lookalike domains that differ from a trusted brand by a single mistyped letter, character swap (rn vs m), or appended keyword (such as microsoft-security-login.com) for phishing or malware delivery.

Deep-dive & defenses → Phishing URL Risk Scanner
Defensive Security

Zero Trust Architecture (ZTA)

Zero Trust Architecture (NIST SP 800-207) is a security model that eliminates implicit trust based on network location ("inside the corporate LAN/VPN") and instead requires continuous authentication, authorization, and encryption for every user, device, and service request.

Deep-dive & defenses → Security Checklist
Network & Pentest

Privilege Escalation

Privilege escalation is the act of exploiting a bug, misconfiguration, or weak permission to gain higher access rights—either vertically (from a standard user or web service account to root/SYSTEM) or horizontally (accessing another user account of the same tier).

Deep-dive & defenses → Linux Privilege Escalation Cheat Sheet
Network & Pentest

Lateral Movement

Lateral movement refers to the techniques an attacker uses after compromising one endpoint to pivot across the internal network to other workstations, servers, and domain controllers in search of high-value assets.

Deep-dive & defenses → Active Directory Cheat Sheet
Network & Pentest

Kerberoasting

Kerberoasting is an Active Directory post-exploitation technique where any authenticated domain user requests Kerberos TGS service tickets for accounts with Service Principal Names (SPNs) and cracks those tickets offline to recover the service account cleartext password.

Deep-dive & defenses → Active Directory Cheat Sheet
Defensive Security

Canary Token (Honeytoken)

A Canary Token (or honeytoken) is a decoy credential, fake API key, tracked document, or unique DNS/HTTP URL planted in sensitive systems that has no legitimate operational use—so any access immediately alerts defenders to an active intrusion.

Deep-dive & defenses → Incident Response First-Hour Cheat Sheet
Defensive Security

CVE & CVSS Score

CVE (Common Vulnerabilities and Exposures) is the standardized global identifier for publicly disclosed security flaws (e.g., CVE-2026-0768), while CVSS (Common Vulnerability Scoring System) rates technical severity from 0.0 to 10.0.

Deep-dive & defenses → Nuclei Pentest Guide
Defensive Security

SIEM & SOAR

SIEM (Security Information and Event Management) aggregates, normalizes, and correlates security logs across an organization to detect threats, while SOAR (Security Orchestration, Automation, and Response) automates triage playbooks and containment actions.

Deep-dive & defenses → Incident Response Cheat Sheet
Defensive Security

EDR & XDR (Endpoint Detection & Response)

EDR (Endpoint Detection and Response) continuously monitors workstation and server process trees, memory, file changes, and network sockets to detect and contain behavioral threats, while XDR extends that correlation across identity, cloud, and network layers.

Deep-dive & defenses → Linux PrivEsc Cheat Sheet
Web App Security

CORS Misconfiguration

A Cross-Origin Resource Sharing (CORS) misconfiguration occurs when a server dynamically reflects an arbitrary Origin header in Access-Control-Allow-Origin alongside Access-Control-Allow-Credentials: true, allowing malicious websites to read authenticated API responses.

Deep-dive & defenses → HTTP Security Headers Cheat Sheet
OSINT & Recon

Banner Grabbing

Banner grabbing is the technique of reading the initial handshake or response headers returned by a network service (such as SSH, HTTP, SMTP, or FTP) to identify the software product, version number, and operating system.

Deep-dive & defenses → Shodan Search Filters Cheat Sheet
Defensive Security

SBOM (Software Bill of Materials)

A Software Bill of Materials (SBOM) is a machine-readable inventory (in CycloneDX or SPDX format) listing every open-source and third-party library, version, and transitive dependency packaged inside an application.

Deep-dive & defenses → Security Checklist
Cryptography & Privacy

Diceware Passphrase

Diceware is a provably random method for generating strong, memorable passphrases by selecting random words from a numbered word list using physical dice or a browser CSPRNG.

Deep-dive & defenses → Passphrase Generator
Cryptography & Privacy

CSPRNG (Cryptographically Secure PRNG)

A Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) produces unpredictable random bytes seeded by operating-system hardware entropy, suitable for generating passwords, cryptographic keys, and session tokens.

Deep-dive & defenses → Random String Generator
