Security Glossary

Twenty terms that unlock every guide on this site — defined in one or two sentences each.

2FA / MFA

Requiring two or more proofs (something you know, have, or are) to sign in.

Brute-force attack

Systematically guessing credentials until one works — industrialized by GPUs against leaked hash databases.

Credential stuffing

Replaying email/password pairs leaked from one breach across other services, betting on reuse.

CSPRNG

Cryptographically secure pseudo-random number generator — unpredictable randomness suitable for keys and passwords. In browsers: crypto.getRandomValues().

Diceware

Generating passphrases by randomly picking words from a published list; entropy = words × log₂(list size).

Entropy (bits)

A measure of unpredictability: log₂ of the search space. Each bit doubles the attacker's work.

Hash (password)

A one-way fingerprint of a password. Slow, salted, memory-hard hashes (Argon2, bcrypt) resist cracking; fast unsalted ones (MD5, SHA-1) do not.

k-anonymity

A privacy model where a lookup (e.g., a breached-password check) is mixed into a set of at least k possibilities, so the server cannot tell what you searched for.

Key stretching

Deliberately slowing password verification (many hash rounds) to make each guess expensive for attackers.

Master password

The single strong passphrase that unlocks a password manager; the one secret worth memorizing carefully.

Passkey

A phishing-resistant credential (FIDO2/WebAuthn): a private key on your device proving itself to a site's public key — no shared secret.

Passphrase

A password made of several random words — long, memorable, and measurably strong.

Password manager

Software that generates, encrypts, and fills unique passwords per account, unlocked by one master password.

Phishing

Impersonating a trusted service to trick you into revealing credentials — the leading cause of account takeover.

Rainbow table

Precomputed lookup of hash→password pairs; defeated by salting.

Rate limiting

Server-side throttling of login attempts; the main defense against online guessing.

Salt

A per-password random value mixed into hashing so identical passwords hash differently.

SIM swapping

Convincing a carrier to move your phone number to an attacker's SIM, hijacking SMS codes.

TOTP

Time-based one-time codes from authenticator apps, rotating every 30 seconds.

WebAuthn

The web standard behind passkeys and hardware security keys, binding credentials to a site's origin.
