Active Directory Enumeration Cheat Sheet: LDAP, Kerberos & SMB

Authorized Active Directory security assessment commands for SMB signing checks, BloodHound collection, SPN Kerberoasting, and AD CS auditing.

Interactive Target Variable Replacer

Customize your target IP, domain, or wordlist below to update every command block on this page automatically.

Command Reference

1. Identify Domain Controllers & SMB Signing Status

Map SMB signing requirements and OS versions across a subnet with NetExec.

nxc smb 192.0.2.10/24 --gen-relay-list smb-unsigned.txt

2. Enumerate Domain Users & Password Policy

Check lockout thresholds before any password auditing.

nxc smb 192.0.2.10 -u "user" -p "pass" --pass-pol

3. Collect Active Directory Graph Data for BloodHound

Run bloodhound-python remotely to map ACLs, group nesting, and sessions.

bloodhound-python -d example.com -u "user" -p "pass" -ns 192.0.2.10 -c All --zip

4. Audit Service Principal Names (Kerberoasting Check)

Identify user accounts with SPNs registered that may use weak service passwords.

impacket-GetUserSPNs example.com/user:pass -dc-ip 192.0.2.10 -request

5. Check for AS-REP Roastable Accounts

Find accounts with "Do not require Kerberos preauthentication" enabled.

impacket-GetNPUsers example.com/ -usersfile users.txt -dc-ip 192.0.2.10 -no-pass

6. Audit Active Directory Certificate Services (AD CS)

Scan for vulnerable certificate templates (ESC1–ESC8) with Certipy.

certipy find -u user@example.com -p "pass" -dc-ip 192.0.2.10 -vulnerable -stdout

7. Enumerate Readable SYSVOL & Group Policy Scripts

Check domain shares for legacy scripts or Group Policy Preferences.

nxc smb 192.0.2.10 -u "user" -p "pass" -M gpp_autologin -M spider_plus

8. LDAP Domain Trust & Delegation Query

List domain trusts and unconstrained delegation hosts via ldapsearch.

ldapsearch -x -H ldap://192.0.2.10 -D "user@example.com" -w "pass" -b "DC=example,DC=com" "(userAccountControl:1.2.840.113556.1.4.803:=524288)"

Frequently Asked Questions

How do organizations defend against Kerberoasting?

Use Group Managed Service Accounts (gMSAs) with automatically rotated 120-character passwords, enforce AES-256 Kerberos encryption instead of RC4, and audit SPNs attached to privileged user accounts.

Why must pentesters always check --pass-pol first?

Querying the domain password policy reveals the Account Lockout Threshold and Observation Window so testers never lock out production user accounts.
