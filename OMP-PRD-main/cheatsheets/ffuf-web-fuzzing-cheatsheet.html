ffuf Web Fuzzing Cheat Sheet: Directories, Vhosts & APIs

Practical ffuf one-liners for directory discovery, virtual host enumeration, GET/POST parameter fuzzing, auto-calibration, and rate limiting.

Interactive Target Variable Replacer

Customize your target IP, domain, or wordlist below to update every command block on this page automatically.

Command Reference

1. Directory Discovery with Auto-Calibration

Fuzz web paths while automatically filtering out baseline soft-404 responses.

ffuf -u https://example.com/FUZZ -w /usr/share/wordlists/common.txt -ac -mc 200,204,301,302,401,403

2. File Extension Fuzzing

Test discovered directories for backup and source extensions.

ffuf -u https://example.com/FUZZ -w /usr/share/wordlists/common.txt -e .php,.bak,.json,.txt,.old -ac

3. Virtual Host (VHost) Subdomain Fuzzing

Discover non-DNS internal virtual hosts by fuzzing the HTTP Host header.

ffuf -u https://192.0.2.10 -H "Host: FUZZ.example.com" -w /usr/share/wordlists/common.txt -ac

4. GET Query Parameter Name Discovery

Find hidden GET parameters accepted by an endpoint.

ffuf -u "https://example.com/api/user?FUZZ=1" -w /usr/share/wordlists/common.txt -ac

5. JSON POST Body Parameter Fuzzing

Fuzz JSON values on API endpoints with custom Content-Type headers.

ffuf -u https://example.com/api/login -X POST -H "Content-Type: application/json" -d '{"user":"FUZZ","pass":"test"}' -w /usr/share/wordlists/common.txt -ac

6. Authenticated Fuzzing with Rate Limiting

Throttle requests to 20 req/sec (-rate 20) and pass a session cookie.

ffuf -u https://example.com/admin/FUZZ -w /usr/share/wordlists/common.txt -b "session=TOKEN_HERE" -rate 20 -ac

7. Recursive Directory Discovery

Automatically queue discovered directories up to 2 levels deep.

ffuf -u https://example.com/FUZZ -w /usr/share/wordlists/common.txt -recursion -recursion-depth 2 -ac

8. Route Fuzz Traffic Through Burp Proxy

Replay matched responses into Burp Suite for manual inspection.

ffuf -u https://example.com/FUZZ -w /usr/share/wordlists/common.txt -ac -replay-proxy http://127.0.0.1:8080

Frequently Asked Questions

What is the best flag in ffuf to avoid flooding Burp Suite?

Use -replay-proxy http://127.0.0.1:8080 instead of -x. The -replay-proxy flag sends only the final matched responses to Burp Suite rather than proxying all 50,000 wordlist guesses.

How do I filter out responses of a specific byte size?

Use -fs <size> to filter by byte size, -fw <words> to filter by word count, or -fl <lines> to filter by line count.
