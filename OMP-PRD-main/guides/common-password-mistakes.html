Common Password Mistakes (and How to Fix Them)

The seven patterns cracking software exploits first — reuse, personal details, keyboard walks, and ‘clever’ substitutions that aren’t.

Fundamentals 6 min read Updated 2026-08-23
On this page
  • Reusing passwords
  • Personal information
  • Predictable patterns
  • Leet substitutions
  • Incrementing on rotation
  • Unsafe storage & sharing
  • The fixes

Password crackers do not guess randomly. They work through dictionaries of real leaked passwords, transformation rules, and demographics — which means most "clever" human tricks are the first things tried. Here are the mistakes that feed them.

1. Reusing passwords

Reuse converts one site's data breach into the takeover of all your accounts via credential stuffing. Fixing reuse is more valuable than strengthening any single password.

2. Personal information

Pet names, birthdays, kids' names, sports teams — all of it is on social media, and all of it is in cracking dictionaries with mangling rules applied. If a friend could guess it, a rig definitely will.

3. Predictable patterns

  • Keyboard walks: qwerty, 1qaz2wsx, zxcvbnm
  • Sequences: abc123, 987654321
  • Repeats: aaaaaa, 112233
  • Dates: Summer2026, John1990 — a word plus a year is a top cracking rule.

Our checker flags all of these locally in your browser.

4. "Clever" leet substitutions

p@ssw0rd, 5up3rman, 1l0v3you — cracking tools apply leetspeak rules exhaustively. Substitutions add complexity for you and essentially zero work for the attacker. Length and randomness beat mangling every time.

5. Incrementing when forced to rotate

Spring2026! → Summer2026! satisfies rotation policies while changing almost nothing. If one version leaks, every version falls. Modern guidance (NIST SP 800-63B) says to rotate on evidence of compromise, not on a calendar.

6. Unsafe storage and sharing

  • Passwords in notes apps, spreadsheets, emails to yourself, or text messages are all searchable, syncable, and leakable.
  • Sending a password over chat leaves it in two devices' history and the service's logs.
  • Browser-stored passwords on a shared or unmanaged machine are one export away from disclosure.

7. The fixes

  1. Move everything into a password manager.
  2. Regenerate reused or weak passwords with a random generator — start with email, banking, and anything reused.
  3. For passwords you must memorize, use 5–7 word passphrases.
  4. Add 2FA so a single mistake is not fatal.

Honest metric: a password you can casually invent is a password a machine can casually guess. Outsource invention to randomness.

Put it into practice: run your next password through the local checker — it never leaves your browser.
