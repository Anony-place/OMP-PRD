How this works — and what it does not do: every score on this page is computed locally in your browser with the published CVSS v3.1 formula (Exploitability = 8.22 x AV x AC x PR x UI; Impact per Scope; Roundup rules exactly as in the specification). Nothing is sent anywhere. CVSS v4.0 vectors are decoded but not scored — v4.0 replaced the formula with macrovector lookup tables, so a real v4.0 score needs the FIRST reference implementation. We would rather show no score than a fake one. A CVSS score is severity, not risk — see the worked example and severity-vs-risk guide.

Frequently Asked

What is a CVSS score?

A 0.0–10.0 rating of how severe a vulnerability is, maintained by FIRST. It combines how easy the flaw is to exploit with how much damage it does, and maps to bands: None 0.0, Low 0.1–3.9, Medium 4.0–6.9, High 7.0–8.9, Critical 9.0–10.0.

How is the v3.1 base score calculated?

Exploitability = 8.22 x Attack Vector x Attack Complexity x Privileges Required x User Interaction. Impact = 6.42 x [1 − (1−C)(1−I)(1−A)] when Scope is Unchanged (a different equation applies when Scope is Changed). Base = Roundup(min(Impact + Exploitability, 10)). This page implements those equations exactly — the worked 9.8 example shows the arithmetic by hand.

Does this calculator compute CVSS v4.0 scores?

No, and neither does any calculator that claims to do it from a formula. v4.0 scores come from macrovector lookup tables (270 equivalence sets, expert-ranked). This tool decodes v4.0 vectors metric by metric; for a v4.0 score use the FIRST reference implementation.

Is a CVSS score a risk rating?

No. CVSS measures severity only — the intrinsic technical impact. Risk also depends on exposure and on whether attackers are actively exploiting the flaw (CISA KEV, EPSS). A 9.8 nobody can reach can matter less than a 7.5 being exploited in the wild.

Are my vectors sent anywhere?

No. Scoring runs entirely in your browser — open the network inspector while you use the tool and you will see no requests. The vector you paste is never uploaded, logged or stored.
