The formula

H = L × log₂(N) — length times the base-2 logarithm of the pool size. Each random lowercase letter adds ~4.7 bits; each mixed-case alphanumeric ~5.95 bits; each full-set character ~6.57 bits; each word from a 1,296-word list ~10.34 bits.

The catch: the formula only holds when selection is truly random. Human choices collapse the effective pool dramatically. Details, tables and attacker models: How Password Entropy Works.
