Cloudflare Verification Asking You to Press Win+R? It’s a Scam

If a website shows a Cloudflare-style “Verify you are human” page and then tells you to press Windows + R, press Ctrl + V, and hit Enter, stop.

That is not a normal Cloudflare verification step.

This is a known social-engineering technique commonly associated with ClickFix. The page looks like a normal CAPTCHA or security verification screen, but instead of keeping the verification inside your browser, it tries to make you execute a command on your computer.

Recent 2026 campaigns have used fake Cloudflare-style verification pages on compromised websites to trick visitors into running attacker-controlled commands. Security researchers and organizations have documented variants that use Windows Run, PowerShell, Windows Terminal, and other trusted system utilities. :chatgpt-content-reference{index="19"}

The most important rule is simple:

A real CAPTCHA should not require you to open Windows Run, PowerShell, Command Prompt, Terminal, or paste an unknown command into your computer.

What Does a Fake Cloudflare Verification Page Look Like?

The attack is designed to look familiar.

You might visit a normal-looking website and suddenly see something resembling a Cloudflare or other human-verification page.

It may contain familiar language such as:

  • “Verify you are human”
  • “Performing security verification”
  • “Checking your browser”
  • “Complete the verification to continue”
  • “Your browser needs verification”

The page may even contain convincing branding and visual elements.

Then something unusual happens.

Instead of asking you to complete the challenge inside the webpage, it tells you to perform operating-system actions.

A typical malicious instruction may look conceptually like this:

  1. Press Win + R.
  2. Press Ctrl + V.
  3. Press Enter.

The dangerous part is not the keyboard shortcut itself.

The problem is that the website may have already placed attacker-controlled text into your clipboard.

When you paste it into the Run dialog or terminal, you may be executing code supplied by the attacker.

Does Cloudflare Really Ask You to Press Win+R?

No.

A Cloudflare human-verification challenge does not need you to open the Windows Run dialog and execute an arbitrary command to prove that you are human.

The University of Houston issued a 2026 warning describing fake CAPTCHA attacks that instruct users to press Win + R, paste a command, and execute it. Its guidance explicitly says legitimate CAPTCHA tests do not require users to copy, paste, or run commands on their devices. :chatgpt-content-reference{index="20"}

This is an important distinction:

CAPTCHA interaction happens in the webpage. Command execution happens on your computer.

When a “verification” page tries to move you from the browser into Windows system tools, treat that as a major security warning.

How the ClickFix Attack Works

ClickFix is a social-engineering technique rather than one specific malware family.

The attacker creates a believable situation in which the victim thinks they need to perform a technical action to fix a problem.

The lure could be:

  • a fake CAPTCHA
  • a fake Cloudflare verification
  • a fake browser error
  • a fake software-update message
  • a fake document error
  • a fake AI-tool installation
  • a fake “Fix” button

The exact story changes, but the underlying trick is similar:

The victim is persuaded to execute attacker-provided content themselves.

A typical browser-based flow looks like this:

Website → fake verification → malicious clipboard content → Win+R/Terminal → command execution → malware

Microsoft and other security researchers have tracked multiple versions of this technique, including newer variants that use Windows Terminal or PowerShell instead of the traditional Run dialog. :chatgpt-content-reference{index="21"}

Why Does the Website Put Something in Your Clipboard?

The clipboard is central to many ClickFix attacks.

The attacker does not want you to manually type a long command. That would make the attack suspicious and inconvenient.

Instead, JavaScript on the malicious page may place text into the clipboard after you interact with the fake verification.

The page then gives you instructions that make the paste operation look like part of the verification process.

You might think:

“I am just following the verification instructions.”

But technically, you may be transferring attacker-controlled text from a webpage into a system command interface.

That is the critical security boundary being abused.

Why Pressing Win+R Is Such a Big Red Flag

Win + R opens the Windows Run dialog.

The Run dialog is designed to launch programs and commands on your computer.

That makes it completely different from clicking a checkbox on a webpage.

Consider the difference:

Action Where it happens Security meaning
Click a CAPTCHA checkbox Browser Normal verification interaction
Select CAPTCHA images Browser Normal verification interaction
Press Win+R Windows Opens a command/program launcher
Open PowerShell Windows Provides command execution capability
Paste an unknown command Windows Potentially executes attacker-controlled content

The website has no legitimate reason to require you to run arbitrary commands simply to establish that you are a human visitor.

What If the Fake CAPTCHA Looks Exactly Like Cloudflare?

Visual appearance is not proof of authenticity.

Attackers can copy logos, colors, fonts, layouts, loading animations, and familiar security language.

They can also compromise legitimate websites and inject malicious content into pages that otherwise look completely normal.

This is particularly important because seeing the attack on a familiar website does not necessarily mean the website itself is intentionally distributing malware.

A compromised website can become a delivery point for a malicious overlay or redirect.

Security researchers have documented campaigns where compromised WordPress sites were used to show fake CAPTCHA pages to visitors. A 2026 government-published analysis of the ShadowCaptcha campaign described compromised websites redirecting visitors toward fake Cloudflare or Google CAPTCHA pages and then using system commands to execute attacker-controlled payloads. :chatgpt-content-reference{index="22"}

So even if you have visited a website safely before, do not automatically trust an unexpected verification screen.

What Should You Do If You See the Win+R Prompt?

If you have not executed the command yet, the response is simple:

  1. Do not press Win+R.
  2. Do not paste anything.
  3. Do not press Enter.
  4. Close the suspicious browser tab.
  5. Do not return to the verification page just to inspect the command.

You do not need to “test” whether the command is malicious.

You already have enough information to reject the interaction.

If the page tells you that something must be executed locally before you can continue, leave the page and access the service through its known official website or application instead.

What If You Pressed Win+R but Did Not Run Anything?

This situation is different from actually executing the command.

If you opened the Run dialog but did not paste or execute the suspicious content, the malicious command may not have been executed.

Close the dialog and browser tab.

If you are unsure whether anything was executed, do not guess. Review what happened and consider performing a security scan before continuing to use the device for sensitive activity.

The important distinction is:

Seeing a malicious webpage is not the same as executing its payload.

What If You Pasted the Command but Did Not Press Enter?

Again, this is different from execution.

If you pasted text into the Run dialog or terminal but did not execute it, close the interface without running it.

Do not copy the command into another website or AI tool simply to see what it does unless you understand the security implications of handling potentially malicious content.

Clear the clipboard by copying something harmless, such as ordinary text, if appropriate.

Then close the malicious webpage.

What If You Pressed Enter and the Command Ran?

This is the situation that requires the most attention.

If you followed the fake CAPTCHA instructions and actually executed the command, treat the device as potentially compromised.

Do not assume that everything is fine because:

  • nothing obvious appeared on screen
  • Windows Defender did not immediately show an alert
  • the browser continued working normally
  • the command window disappeared quickly
  • you did not see a traditional malware installer

ClickFix campaigns can use legitimate Windows utilities and user-executed commands as part of the infection chain. The exact payload varies by campaign, so the visible behavior is not a reliable indicator of whether the system was compromised. :chatgpt-content-reference{index="23"}

First: stop using the potentially compromised device for sensitive logins

If you have strong reason to believe that malware executed, avoid immediately logging into your email, banking, password manager, cryptocurrency accounts, or work systems from that computer.

Infostealer malware may target browser credentials, cookies, session information, cryptocurrency wallets, and other sensitive data.

Second: disconnect the device if compromise is credible

Disconnecting a potentially compromised system from the network can help limit ongoing communication with attacker infrastructure while you investigate.

This does not magically remove malware, but it can reduce the opportunity for additional data transfer.

Third: use a trusted device for important password changes

If you believe the infected computer may have exposed credentials or session tokens, use a separate trusted device where practical to secure important accounts.

Prioritize:

  1. primary email
  2. password manager
  3. banking and financial accounts
  4. work accounts
  5. cloud storage
  6. social-media accounts
  7. other accounts containing sensitive information

Do not simply change one password and assume the problem is solved.

If malware captured session cookies or authentication tokens, changing the password alone may not invalidate every active session. Review the account's active sessions and sign out unknown devices where the service provides that capability.

Could a Fake CAPTCHA Steal Your Chrome Passwords?

Potentially, yes.

That is one reason this technique matters to OopsMyPassword readers.

Information-stealing malware can target browser-stored credentials and other authentication material. Some campaigns also target cookies and session information.

This means a fake CAPTCHA can become an account-security incident even though the attack initially looked like an ordinary webpage verification.

If you executed an unknown command and subsequently suspect compromise, treat browser-stored passwords as potentially exposed until you have established otherwise.

After securing the device and accounts, review your password-management setup and replace credentials that may have been exposed.

Can Antivirus Detect ClickFix?

Security software is an important layer of defense, but it should not be treated as permission to execute unknown commands.

ClickFix is designed around social engineering: the victim is convinced to perform an action that the attacker wants.

That means the strongest first defense is recognizing the malicious instruction before executing it.

Microsoft's recent analysis of ClickFix variants highlights why the technique is effective: attackers can abuse legitimate system tools and rely on the victim to perform the execution step. :chatgpt-content-reference{index="24"}

Your security software is therefore a backup layer, not a replacement for safe behavior.

Why These Scams Work So Well

The trick is psychological rather than technically complicated.

People have been trained to expect security checks on the web.

We routinely see:

  • CAPTCHAs
  • browser checks
  • cookie prompts
  • security warnings
  • software update notices
  • anti-bot systems

Most users do not carefully analyze every verification screen. They simply complete it and continue to the content they wanted.

ClickFix abuses that habit.

The attacker does not need to convince you that malware is safe.

They only need to convince you that the command is part of a routine verification process.

The One Rule Worth Remembering

You do not need to memorize every ClickFix variant.

You do not need to recognize every malware family.

You do not need to identify whether the page is powered by Cloudflare, Google, another CDN, or a fake copy.

Remember this:

If a website tells you to open Win+R, PowerShell, Command Prompt, Windows Terminal, or another system shell and paste a command to prove you are human, stop.

That is not a normal CAPTCHA workflow.

Quick Checklist

If you see a suspicious “Verify you are human” page, ask:

  • Does the verification stay entirely inside the browser?
  • Is it asking me to open Win+R?
  • Is it asking me to open PowerShell or Terminal?
  • Is it asking me to paste text I did not write?
  • Is it asking me to run a command?
  • Is it telling me to disable security software?
  • Is it asking me to install an unexpected program?

If the answer to any of the command-execution questions is yes, stop the interaction.

Bottom Line

A fake Cloudflare verification page that asks you to press Win + R, paste a command, and press Enter is not a clever new CAPTCHA.

It is a social-engineering attack designed to turn your own computer into the execution mechanism.

The page may look professional. The website may normally be legitimate. The Cloudflare branding may look authentic. The instructions may be written perfectly.

None of those things makes the command safe.

Real human verification happens inside the browser. A request to leave the browser and execute unknown commands is a security red flag.

If you only saw the page, close it.

If you pasted something but did not execute it, stop and close the interaction.

If you executed the command, treat the device as potentially compromised and begin account and device-response steps from a trusted environment.

And if you remember only one thing from this article, remember this:

No CAPTCHA needs you to run someone else's command.
