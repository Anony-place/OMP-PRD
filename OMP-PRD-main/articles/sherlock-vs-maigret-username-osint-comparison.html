Sherlock vs Maigret: Which Username OSINT Tool Should You Use?

Sherlock vs Maigret: the short answer

Use Sherlock when you need a fast answer to "does this username exist?" across 400+ sites. Use Maigret when one username deserves a full investigation — 3000+ sites, leak checks and a written HTML or PDF report. Investigators who do this regularly end up using both: Sherlock for triage, Maigret for depth.

Side-by-side comparison

SherlockMaigret
Sites checked400+3000+
Data-leak checksNoYes
ReportsText file per usernameHTML and PDF reports
Profile detailsExistence plus linkIDs, linked accounts, interests
Ease of useOne commandOne command, more flags
CostFree, open sourceFree, open source

When Sherlock wins

Speed and simplicity. A 30-second triage of a suspicious handle, a quick impersonation check, or a first pass before deciding whether a deeper investigation is worth it. If you are new, start here — and if even Sherlock feels heavy, WhatsMyName answers in the browser with zero install.

When Maigret wins

Depth and documentation. Due diligence, fraud review, or any case ending in a report someone else must read. The HTML report alone justifies the slightly longer run time.

The practical workflow

Run Sherlock first. If the username exists in interesting places, run Maigret on the same handle for the full picture, then open the top hits by hand and verify each one. Both tools live in our OSINT Hub with install steps.
