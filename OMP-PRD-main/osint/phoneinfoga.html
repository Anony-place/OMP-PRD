PhoneInfoga

Scan a phone number for carrier, country, linked accounts and mentions. Free, open-source.

Overview

PhoneInfoga is an open-source phone number investigator. Enter a number in international format and it reports the carrier and country, checks the number against data-leak databases, and searches for public mentions and linked messenger accounts.

Version 2 runs as a local web server, so beginners never have to leave the browser while advanced users keep the terminal workflow. The one-command Docker deployment removes the usual dependency pain, which makes it practical for scam triage desks and fraud teams that need answers in minutes, not setup hours.

Key features

  • Carrier, country and line-type detection from any number
  • Checks leaks and public mentions of the number
  • Local web UI plus the classic terminal workflow
  • One-command Docker deployment — no dependency hell
  • Number reputation signals for scam and spam triage
  • Free and open source (GPL-3.0)

Install & first run


# Easiest: run with Docker

docker pull sundowndev/phoneinfoga:latest

docker run -it -p 5000:5000 sundowndev/phoneinfoga serve --port=5000



# Then open http://localhost:5000 in your browser,

# or scan directly from the terminal:

docker run -it sundowndev/phoneinfoga scan -n +33612345678

Real-world example

A text message claims your parcel is held and links a "redelivery" page asking for card details. Copy the sender number into PhoneInfoga in international format. The scan returns the real carrier and country plus any leak or mention history — compare that with the story: a domestic parcel service texting from a foreign prepaid range is a failed check.

Screenshot the result, block the number and report the message as smishing. If the number shows prior scam reports, include them in the report so the pattern is visible.

Common questions

What format does the number need?

International format with the country code, for example +33612345678.

Is PhoneInfoga free?

Yes. It is free and open source under the GPL-3.0 license.

Web or terminal?

Both. Version 2 serves a local web UI, and the classic terminal scan still works.
