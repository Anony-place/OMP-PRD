Sherlock

Hunt down a username across 400+ social networks and websites. Free, open-source, runs on your machine.

Overview

Sherlock is the best-known username search tool in open-source intelligence: give it one handle and it checks that username across 400+ social networks and websites, then saves every hit to a text file with a direct link to the profile. It runs entirely on your own machine — no account, no API key, nothing sent to third parties — which is why it is the default first command in username investigations and a permanent fixture in OSINT courses.

What a Sherlock run actually tells you

Each hit means one site reports that the username exists there. That is a lead, not an identity: handles get recycled, impersonated and abandoned, and soft-404 sites can report a hit for almost anything. Sherlock's job is fast, wide triage — the human job is verification. Open the hits, look for corroborating details (same avatar, same bio, matching posting history), and record the URL and date of anything you keep. Two matching identifiers is still the minimum to link an account to a person.

The flags that matter in practice

Experienced users rarely run it bare. --print-found with a short --timeout cuts the noise from slow sites. --site limits a run to specific platforms when you only care about one. --csv, --json and --xlsx export results for reports, while --folderoutput keeps multi-username runs tidy — one file per user. --proxy routes through a socks5 proxy, and --nsfw opts into adult sites that stay excluded by default.

Sherlock vs Maigret vs WhatsMyName

Sherlock covers 400+ sites with a clean, scriptable CLI. Maigret grew from the same idea and goes much wider — 5,900 sites, tag filters and HTML/PDF reports — at the cost of a heavier run. WhatsMyName is the instant browser check, but its dataset was frozen when the project was archived in November 2026 — the archive's farewell names Sherlock among the maintained successors. The common workflow is a quick check first, then Sherlock (or Maigret) for the deep pass. See the Sherlock vs Maigret comparison for a side-by-side.

Responsible use

Looking up whether a username appears on public sites is ordinary, legal OSINT — recruiters, journalists and safety researchers do it daily. Only investigate accounts you have a legitimate reason to look into, respect each site’s terms, and never use results to harass, doxx or impersonate anyone.

Key features

  • 400+ social networks and sites checked per run
  • Runs locally — no account, no API key, nothing leaves your machine
  • Export to text, CSV, JSON or XLSX for reports
  • --site targets specific platforms; --timeout tames slow ones
  • --proxy support for socks5 routing
  • Multi-username runs with per-user output folders
  • --nsfw opt-in for the adult sites excluded by default
  • Free and open source (MIT license)

Install & first run

  1. Install with pipx (or uv/pip): pipx install sherlock-project — or skip installation entirely and use Docker: docker run -it --rm sherlock/sherlock.
  2. Run it: sherlock username.
  3. Read the console hits, or open the generated username.txt with direct profile links.
  4. Add --print-found --timeout 10 for a cleaner run; add --csv or --json when the results feed a report.
  5. Verify each hit by hand — a hit proves the handle exists on the site, not who is behind it.

Real-world example

A marketplace seller contacts you on Telegram with a great price and a username that also appears as their "shop name". Before sending any money, run that handle through Sherlock. In a few minutes you get a list of everywhere the name exists: perhaps a matching Instagram with three years of posts and a GitHub with real commits — or perhaps nothing at all outside Telegram, which is itself an answer.

Open the two or three strongest hits. Compare avatars, writing style and account ages. If the Instagram joined last week and the photos look stock, walk away. If everything lines up across years, you have done in ten minutes what used to take an afternoon of manual searching.

Common questions

Is Sherlock free?

Yes — free and open source under the MIT license. It runs entirely on your own machine: no account, no API key and no data sent to third parties.

How many sites does Sherlock check?

400+ social networks and websites, ordered by traffic. --site narrows a run to specific platforms, and the site list is easy to extend if a community site is missing.

Why do some results look like false positives?

Some sites return a found-page for any username (soft-404s). Use --print-found with a short --timeout, and verify unusual hits by opening the profile yourself. A hit is a lead, not proof of identity.

Sherlock or Maigret — which should I use?

Sherlock for fast, focused runs and scripts; Maigret when you need the widest coverage (5,900 sites), tag filters and HTML/PDF reports. The Sherlock vs Maigret comparison lays out the differences. Both are actively maintained — unlike WhatsMyName, whose dataset was frozen in November 2026.

Can I run Sherlock on many usernames at once?

Yes — pass several usernames in one command and use --folderoutput to keep each user’s hits in its own file, plus --csv or --json for spreadsheet and pipeline use.

Is checking usernames with Sherlock legal?

Looking up whether a username appears on public sites is ordinary OSINT and legal in most contexts. Purpose is the line: only investigate accounts you have a legitimate reason to look into, and never use results to harass or doxx anyone.

Does it need an account or API key?

No. Sherlock queries the sites directly from your machine. If you need anonymity or rate-limit relief, route it through your own proxy with --proxy socks5://127.0.0.1:1080.
