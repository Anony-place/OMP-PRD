Overview

WhatsMyName is a browser-based username checker maintained by the WebBreacher project. Type a username and it tests it against hundreds of websites in seconds, showing found profiles as clickable links. Because it runs entirely as a web page there is nothing to install and no command line needed — the best first tool for beginners.

Experienced investigators use it as a triage step before heavier tools: a 30-second WhatsMyName run tells you whether a handle is worth a full Sherlock or Maigret pass. The underlying site list is downloadable, so the same checks can run offline or inside your own scripts.

Key features

  • Zero install — runs as a single web page
  • Hundreds of sites checked in seconds with clickable results
  • Downloadable site database for offline and scripted checks
  • No account and no tracking of your searches
  • Dataset maintained and used by investigators worldwide
  • Free forever, open source (MIT)

Install & first run

No installation needed: it runs in your browser.

  1. Open the WhatsMyName web app below.
  2. Type the username and press enter.
  3. Click any found result to open and verify the profile.

Real-world example

A stranger's DM offers you a part-time "rating task" job and asks you to move to another chat app. Before replying, paste their username into WhatsMyName. In thirty seconds you see whether the handle exists anywhere else: a years-old gaming profile suggests a real person, while zero hits anywhere suggests a handle invented for this scam.

Use the result to decide the next step. Real presence plus a verifiable history? Continue carefully. No presence at all? Block, report, and optionally escalate the handle to Sherlock for a deeper pass.

Common questions

Do I need to install WhatsMyName?

No. It runs entirely as a web page — open it, type a username, read the results.

Is my search tracked?

There is no account and no login. The checks run from the page itself; still, treat every lookup as professional activity.

Can I use its data offline?

Yes. The underlying site list is downloadable, so the same checks can run offline or inside your own scripts.
