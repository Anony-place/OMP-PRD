Privacy Policy

Last updated: August 23, 2026. Plain language, because privacy policies should be read, not scrolled past.

The one-paragraph version

Passwords you enter into OopsMyPassword's local tools are processed in your browser's memory and nowhere else. We do not store password history, we do not put passwords in URLs, we do not send what you type to analytics, and there are no user accounts that could tie anything to you.

1. Local processing of passwords

  • The Password Checker, Generator, Passphrase Generator, Entropy Calculator and Password Health audit run entirely client-side. The password value lives only in browser memory while the tab is open.
  • We do not transmit, log, persist, or otherwise observe password inputs.
  • Passwords are never included in URLs, query parameters, hash fragments, or referrer headers.
  • If this site ever includes error reporting or analytics, it is configured such that input values — passwords included — can never be part of a payload.

2. No accounts, no profiles

OMP has no registration, login, or identity system. We therefore hold no account database to breach. The only browser storage used is for preferences (theme) and, on the Security Checklist page, your checkbox progress — both of which stay on your device and contain no personal information.

3. The breach-check demo

The Breach Check page hashes input locally with SHA-1 (WebCrypto) and compares a 5-character hash prefix against a small corpus bundled with the page. No network request is made with any part of your input or its hash. The demo is labeled accordingly and does not represent a live breach database query.

4. Hosting and server logs

Like nearly every website, the static-hosting provider serving these files processes standard technical metadata (IP address, user agent, requested path) to deliver pages, and retains it briefly for security and reliability. We do not sell, rent, or share that data.

5. Third-party services

The current build embeds no third-party trackers, fonts, CDNs, or analytics. If any third-party service is added in the future (for example, an opt-in k-anonymity breach-lookup API), this policy will be updated to name the service, document exactly what data it receives (ideally only a 5-character hash prefix), and make the feature explicit and consent-based.

6. Children

OMP is an educational tool directed at a general audience and collects no personal information from anyone, including children.

7. Changes to this policy

Material changes will be posted on this page with an updated date. We will never claim compliance certifications we have not obtained; where a formal legal regime applies to how you use this site, consult qualified counsel.

8. Contact

Privacy questions and security reports: see the contact page or our security policy.
