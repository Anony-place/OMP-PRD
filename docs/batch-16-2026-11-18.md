## Connector lesson (added to the playbook)

Older article rows store **real em-dash characters (—)**, not `&mdash;` entities — a REPLACE
anchored on `&mdash;` silently matches 0 rows (RETURNING shows row_count 1 but
`LIKE '%...%' = false`). Always RETURNING with a LIKE proof, and match the anchor's
existing entity style. (My new inserts use `&mdash;` entities consistently.)
