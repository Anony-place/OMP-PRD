# Batch-24 — A-to-Z audit fixes (2026-11-18)

Source: user-supplied `oopsmypassword_audit_report.pdf` (35 pages/endpoints checked, 15/15
tools functional, 13 bugs). Fixed all 13 per the report's roadmap.

## High
1. **Search modal (Ctrl+K)** — root cause found: `.omp-sr-title`/`.omp-sr-desc` were INLINE
   spans, so `nowrap/ellipsis` never clipped → titles+descriptions concatenated on one line
   AND overflowed the dialog horizontally. Fixed with `display:block` + `margin-top`.
   Also hardened reveal: `.omp-open` now added synchronously + rAF + 120ms fallback
   (dialog starts opacity:0; a throttled rAF left an invisible modal over a visible
   backdrop — matches the report's "off-viewport when scrolled" symptom). Overlay got
   explicit top/left/right/bottom + box-sizing (audit guessed "missing position:fixed";
   it had fixed — the invisible-dialog path was the real gap).
2. **/cvss-calculator default red error** — `defaults()` set `AC='N'`, invalid in CVSS 3.1
   (L/M/H) → "bad value N for AC; missing base metric: AC" on every load. Now defaults to
   a valid neutral vector (AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:N) = still shows "0.0 None"
   but error-free. Module regression-checked: Log4Shell preset = 10.0, exports intact.

## Medium
3. **Tool input widths** — `.input` had no width rule (browser-default ~180px boxes on
   /hash-inspector, /url-scanner, /cvss-calculator). `width:100%; box-sizing:border-box`.
4. **Entropy crack-time table** — was already wrapped in `.table-scroll`, but scroll was
   invisible (no scrollbar styling = looked clipped). Added visible thin scrollbars;
   also fixed the layout.py `table-scroll` a11y regex to match multi-class attributes
   (entropy's `class="table-scroll mt-16"` was skipping the tabindex/aria-label).
5. **Dark-mode active nav contrast** — explicit per-theme rules: #F8FAFC on rgba(purple,.32)
   in dark, #0F172A on rgba(purple,.18) in light.
6. **/breach-check Enter submits** — input+button wrapped in `<form data-breach-form>`
   (submit → button click), per the report's recommendation.
